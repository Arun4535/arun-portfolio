# Deploy Arun's Portfolio

## Option A — GitHub Pages

Free, no account needed beyond GitHub.

1. Create a new GitHub repo named `arun-portfolio`.
2. Upload `index.html` to the repo.
3. Go to repo Settings → Pages → Source: Deploy from branch → `main`.
4. Your site is live at: `https://Arun4535.github.io/arun-portfolio`.
5. It usually takes 2-3 minutes to go live.

## Option B — Vercel

1. Go to `vercel.com` → Sign up with GitHub.
2. New Project → Import your `arun-portfolio` repo.
3. Framework: Other (static).
4. Deploy → site is live at: `https://arun-portfolio-green.vercel.app/`.
5. Custom domain: Add `arunkhanchandani.dev` in Vercel settings. Then point domain DNS to Vercel at your domain registrar.

## Two Things To Update After Deployment

1. Replace `#` in the Download Resume button with your PDF resume URL.
2. Replace `#` in the Live Demo button with your DocSense live URL once it's deployed.
